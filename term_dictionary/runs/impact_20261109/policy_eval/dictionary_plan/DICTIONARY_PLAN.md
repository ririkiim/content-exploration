- 영어 키워드는 빈도가 집중돼 있음: 상위 100개 = 부착 38%(연결 35개), 상위 300개 = 55%(91개), 상위 1,000개 = 76%(240개). **상위 약 1,000개만 연결해도 영어 부착의 대부분 확보.**

## 3. 구축 순서 (이번 주)
| 일 | 작업 | 산출 | LLM·Wikidata |
|---|---|---|---|
| 1 | 사전 v0 파일 스키마 확정 + 기존 자산 이관 | `keyword_dictionary_v0.csv`(node, lang, surface, kind[original/translation/alias/variant], 출처 kmdb/tmdb), `keyword_relations_v0.csv`(a, b, relation[EXACT/CLOSE/RELATED/BROADER], evidence_type, evidence, weight, status[code_auto/llm_only/candidate]) — edges.csv 6,565·원장 이관, E5 단독은 candidate | 없음 |
| 2 | S1 Wikidata 캐시: 한국어 라벨→표시명/번역, 별칭→검색 표현, P1889 차단 | +258 번역, +233 별칭 | 없음 |
| 3 | S5 복합어 포함 + S2 병렬작품 + S4: 증거 조합별 등급화(독립 소스 2개↑ = CLOSE, 1개 = RELATED, E5 단독 = candidate) | +~800 후보 중 일부 | 없음 |
| 4 | 갭 확인: 상위 N 영어 키워드 중 여전히 미커버 목록 확정, 기존 한국어 키워드(14,590) 중 후보 목록 생성 | `gap_top1000.csv` | 없음 |
| 5 | **(승인 필요, 선택)** 갭 번역: 상위 ~700~1,000개 영어 키워드에 대해 기존 한국어 키워드 후보 중 선택 또는 "없음". v3 단가(요청당 약 $0.011) 기준 $8~11 추정. 결과는 pair_key 원장에 llm_only로 저장 | 상위 영어 부착 커버리지 대폭 상승 | LLM 신규 호출(승인 시) |
| 6 | 사전 v0로 `edges.csv` 재생성 → 프로토타입 전후 비교(같은 5작품 + 표본 300): 영어 번역 커버리지, 한영 교차 비율, 결과 수, 상위 경로 | 전후 비교표 | 없음 |

LLM 단계(5)를 생략하면 영어 부착 커버리지 상한은 약 55%(후보 포함, 확정 아님), 포함하면 상위 1,000개 기준 약 76%까지 가능. 553쌍 보류분($12)도 같은 방식으로 CLOSE/RELATED 보강에 쓸 수 있음.

## 4. 사전 데이터 규칙
- 원본 키워드·출처는 절대 변경/삭제하지 않음. 번역·별칭은 별도 행(kind)으로 추가.
- EXACT는 병합이 아니라 관계. 한국어 표시명은 개념별로 계산(EXACT/번역 중 키워드 부착 수가 큰 쪽).
- 근거 유형 분리: code / wikidata_cache / parallel_works / e5_candidate / llm_only. 줄거리 검색은 kind와 weight로 필터(번역·별칭만, 관련 표현은 낮은 신뢰).
- 의미가 다른 쌍(`복수(plural)` 등)은 병합 금지: P1889와 NOT_SAME 판정을 차단 신호로 사용.

## 5. 확인 지표 (사전 확장 전후)
영어 키워드 번역 연결률(개수/부착 기준), 상위 300·1,000개 커버율, 프로토타입 상위 10개 중 한영 교차 비율, 시작 작품 중 결과가 있는 비율, 2홉 결과 구성, 규칙별 표본 오류 목록(1회성).
